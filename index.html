עמוד 1 — 01 יסודות AI, ML, Dataset ווקטורים

AI, ML וחשיבה ניהולית

AI מוצג בשיעור הראשון כמושג רחב של מערכות ומכונות שמחליפות או מחקות פעולות אנושיות. Machine Learning הוא ליבת היכולת ללמוד דפוסים ולקבל החלטות. הדגש של הקורס הוא יישומי וניהולי: לדעת מה ניתן לבצע בעזרת AI, מה ניתן לדרוש מעובדים, וכיצד להשתמש בו כמכפיל כוח.

Regression = חיזוי ערך מספרי. Classification = קטגוריה. Reinforcement Learning = החלטה אדפטיבית לפי מצב ותגמול/עונש. Anomaly Detection = לימוד המצב התקין וזיהוי חריגה ממנו. Deep Learning מוצג כתת-תחום של ML המבוסס על רשתות נוירונים.

RAG, GraphRAG, Skills ו-Progressive Disclosure

RAG מחזיק ידע חיצוני גדול ומחזיר רק את הקטע הרלוונטי. GraphRAG מוסיף ישויות, קשרים וקהילות ומיועד גם לשאלות רוחביות. Skill הוא שכבת תפקיד/מומחיות/כלים/הנחיות. Progressive Disclosure טוען מטא-נתונים, הוראות ומשאבים לפי צורך.

Multi-Agent, Flat Mesh ו-Hierarchical Orchestration

Multi-Agent Systems מאפשרים כמה סוכנים מתמחים. Flat Mesh מבוזר ופועל ללא היררכיית תיאום מובנית, אך עלול ליצור תקורת תקשורת, Fragmentation ו-Thrashing Review. Hierarchical Orchestration מחלק את העבודה לשכבות Governance, Execution ו-Compliance.
